# Keys and commands

Every command with what it does and its default keys, generated from ronin's command table and built-in configuration,
so this page says what the program does. Keys are written as describe-key (`C-h k`) prints them: the notation is on
[First steps](first-steps.html#key-notation), how to change them under [Configuration](configuration.html#rebinding-keys).

Each section below is a section of the configuration file. The keys of `[keys minibuffer]`, `[keys search-results]`,
`[keys compilation]`, `[keys command-list]`, `[keys git-changes]` and `[keys isearch]` come first in their places;
every other key falls through to `[keys]`. A command bound nowhere is run with `M-x` and its name.
