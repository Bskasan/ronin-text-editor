git

C-x g shows the uncommitted changes of the project's git work tree in a box over the windows: every file git status lists, with its two-letter status, and the selected file's diff against HEAD. It only reads: nothing is staged, committed or reverted. git runs in the background, so typing never waits for it; the box opens once git has answered, and without git or outside a work tree a message says so and nothing opens.

keyscommandwhat it does
C-x gshow-git-changesthe changed files and their diffs

While the box is open:

Settings

ronin runs git.exe from PATH, or the program git_path names. A diff is cut after git_diff_max_lines lines and the file list after git_status_max_files files, each with a last line saying so; a git that prints nothing for git_timeout_ms is stopped. The view needs git 2.15 or later and does not scroll diffs sideways.
