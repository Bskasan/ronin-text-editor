Roadmap

What may come after 1.0, in no fixed order and without dates:

  • Editing: auto-save, prefix arguments (C-u), the mark ring, rectangles, ESC as Meta.
  • Search: regular expressions, whole-word search, project-wide replace, a match count in isearch.
  • Text: legacy code pages and UTF-16 without a byte order mark, wide characters and emoji, a fallback font, line numbers.
  • Speed on extreme input: very long lines, and saving on a background thread.
  • Projects and builds: an index kept current from change notifications, run and debug commands, several build commands per project, user-defined error formats.
  • git: staging, committing and reverting from the git changes view.
  • Windows: undo of window changes.

Not planned, by design: a language server or tree-sitter, proportional fonts, ligatures, bold and italic, tabs, menus, toolbars and scroll bars.
