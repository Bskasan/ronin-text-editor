# ronin 1.0.1

ronin is a small, fast code editor for Windows that looks and works like Emacs: windows side by side, a minibuffer and
Emacs' keys, with no tabs, menus or scroll bars. It is one executable of under half a megabyte, written in C with no
dependencies, and it highlights and indents Jai, C, C++, C#, JavaScript and TypeScript.

1.0.1 is a bug-fix release. Replace ronin.exe with the new one; your ronin.conf, your themes and your keys stay as they
are.

## Fixed

- **The git changes view (`C-x g`):** pressing `RET` or double-clicking a file before its diff has appeared used to open
  the file at line 1. It now opens it at its first change as soon as git answers, and the status line says it is
  waiting. Any other key, `C-g` or a click elsewhere cancels.
- **The documentation site:** a link to a section whose title appears more than once on a page, such as each version's
  "Changed" in the changelog, now goes to the right one, as it does on GitHub.

## Numbers

ronin's own work for a key, the command and building its frame, takes 20 to 30 µs; that is not the time until the key
is on screen, which also waits for Windows' compositor and the display's next refresh. The first frame is on screen
about 170 ms after the start. An idle ronin uses no CPU and about 60 MB of memory, most of it the graphics driver's.
ronin.exe is 471,040 bytes and imports only kernel32, user32 and gdi32.

## Download

**ronin-1.0.1-windows-x64.zip** (below, under Assets). Unzip it anywhere and run `ronin.exe`: Windows 10 or 11, x64, no
installer, nothing else to install. The zip holds ronin.exe, README.md, CHANGELOG.md, LICENSE, THIRD_PARTY.md and
samples\ (one file per language to try).

The exe is not signed, so the first start may show "Windows protected your PC" (SmartScreen): choose **More info**, then
**Run anyway**.

The zip's SHA-256 is in SHA256SUMS.txt, beside it under Assets. In PowerShell: `Get-FileHash ronin-1.0.1-windows-x64.zip`.

## Known limits

Monospace text only (wide characters and emoji show as a box); no line wrapping or line numbers; literal search only (no
regular expressions); no prefix arguments, rectangles or auto-save; UTF-8 and UTF-16 with a byte order mark only; the git
view only reads; the themes are dark. After a crash of ronin, each modified buffer that belongs to a file is written to a
recovery file when that is possible and offered at the next start; buffers without a file (such as `*scratch*`), a
power loss and ronin ended from outside are not covered (auto-save is not there yet). The full list: https://bskasan.github.io/ronin-text-editor/limits.html
