# ronin 1.0.0

ronin is a small, fast code editor for Windows that looks and works like Emacs: windows side by side, a minibuffer and
Emacs' keys, with no tabs, menus or scroll bars. It is one executable of under half a megabyte, written in C with no
dependencies, and it highlights and indents Jai, C, C++, C#, JavaScript and TypeScript.

A keystroke's command and frame take 20 to 30 µs, the first frame is on screen about 170 ms after the start, an idle
ronin uses no CPU and about 60 MB of memory, and ronin.exe is 470,016 bytes that import only kernel32, user32 and gdi32.

## Download

**ronin-1.0.0-windows-x64.zip** (below, under Assets; 263,347 bytes). Unzip it anywhere and run `ronin.exe`: Windows 10
or 11, x64, no installer, nothing else to install. The zip holds ronin.exe, README.md, CHANGELOG.md, LICENSE,
THIRD_PARTY.md and samples\ (one file per language to try).

The exe is not signed, so the first start may show "Windows protected your PC" (SmartScreen): choose **More info**, then
**Run anyway**.

## Highlights

- Emacs' editing model and default keys: point and mark, the kill ring shared with the clipboard, undo and undo-redo,
  isearch, query-replace, M-x with completion. Every key can be rebound in one text file, applied as soon as it is saved.
- Highlighting and automatic indentation for six languages from hand-written lexers, incremental even in a 100 MB file.
- Windows side by side or above each other, sized with the keys or the mouse.
- Projects: open any file of the tree by fuzzy matching (C-x p f), honoring .gitignore; search the whole project on
  background threads (C-x p g), or one buffer with occur.
- Builds: C-x p c runs your build; errors of MSVC, GCC / Clang, tsc and Jai are recognized, and M-g n jumps to each.
- Multiple cursors, as in Emacs' multiple-cursors package; typing at 10,000 cursors takes about 2 ms.
- The command list (C-S-p): every command, what it does and its keys, filtered as you type.
- The git changes view (C-x g): the uncommitted changes and each file's colored diff, in a box over the windows.
- Terminals: C-c t opens one in the file's directory, C-c a one in the project's root running claude or codex.
- Five dark themes (M-x set-theme), and recovery files for unsaved work if ronin ever crashes.

## Known limits

Monospace text only (wide characters and emoji show as a box); no line wrapping or line numbers; literal search only (no
regular expressions); no prefix arguments, rectangles or auto-save; UTF-8 and UTF-16 with a byte order mark only; the git
view only reads; the themes are dark. The full list: https://bskasan.github.io/ronin-text-editor/limits.html
