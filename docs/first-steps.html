First steps

Key notation

Keys are written as in Emacs: C- is Ctrl, M- is Alt, S- is Shift; RET is Enter, SPC the space bar, DEL Backspace; C-x C-s means Ctrl+X, then Ctrl+S. A key matches by the character it types in your keyboard layout: C-/ is Ctrl with whichever key types /. Unlike Emacs, ESC cancels (as C-g does).

The command list

C-S-p lists every command with a one-line description and its keys in the current window. Typing filters it (fuzzy, on the name, the description or both); the arrows, C-n / C-p and C-v / M-v move; RET or a double click runs the selected command as M-x would; C-g, ESC or a click outside close it.

M-x

M-x reads a command's name in the minibuffer, with completion: a candidate matches when every space-separated word of the input occurs in it, ignoring case. TAB completes, RET runs the selected candidate, C-g gives up. Every command has a name, so a command without a key is one M-x away.
